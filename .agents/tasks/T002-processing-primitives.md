# T002 — Image Processing Primitives

Status: PLANNED

## Objective

Implement tested, framework-independent operations for decode, crop, resize, format conversion, and metadata extraction.

## Acceptance criteria

- [ ] Supported local images can be decoded.
- [ ] Crop calculations produce the requested aspect ratio.
- [ ] Resize produces exact requested pixel dimensions.
- [ ] Format conversion works for required MVP formats.
- [ ] Tests cover edge cases.
- [ ] Processing functions have no React/UI dependencies.
