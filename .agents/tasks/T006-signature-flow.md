# T006 — Signature Upload and Drawing

Status: PLANNED

## Objective

Implement signature upload and a lightweight drawing canvas.

## Acceptance criteria

- [ ] User can draw a signature with a pointer/touch input.
- [ ] Clear/undo/reset works.
- [ ] Uploaded signatures can be cropped.
- [ ] Empty margins can be trimmed.
- [ ] Output is passed through the same requirement/validation engine.
