# T003 — Constraint-Based File Size Optimizer

Status: PLANNED

## Objective

Build an optimizer that meets file-size constraints with the best practical quality.

## Acceptance criteria

- [ ] Maximum byte size can be satisfied when a valid candidate exists.
- [ ] Minimum/maximum ranges are supported.
- [ ] Exact dimensions remain unchanged when mandated.
- [ ] Search converges quickly.
- [ ] Failure states explain that the requested constraints may be impossible.
- [ ] Unit tests cover multiple image sizes and target limits.
