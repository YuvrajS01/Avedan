# T005 — Guided Camera Capture

Status: PLANNED

## Objective

Add a browser camera capture experience with clear permission handling and capture guidance.

## Acceptance criteria

- [ ] Camera permission request is handled gracefully.
- [ ] Capture works on supported browsers.
- [ ] Unsupported/denied camera access provides upload fallback.
- [ ] Captured frame feeds into the existing photo processing pipeline.
- [ ] No camera frame is uploaded to a server.
