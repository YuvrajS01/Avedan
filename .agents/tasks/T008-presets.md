# T008 — Form Preset Registry

Status: PLANNED

## Objective

Introduce data-driven form presets and search/select UX.

## Acceptance criteria

- [ ] Presets validate against the typed schema.
- [ ] Presets display source and last-verified date.
- [ ] Selecting a preset produces `ImageRequirements` for each asset type.
- [ ] UI can distinguish verified and stale/unverified entries.
- [ ] No preset is described as guaranteeing official acceptance.
