# Product Roadmap

## Milestone 0 — Foundation

Repository, application shell, architecture boundaries, tests.

## Milestone 1 — Core utility

Photo processing and signature preparation with exact constraints and file-size optimization.

## Milestone 2 — Capture and validation

Camera mode, technical validation, better mobile UX.

## Milestone 3 — Form intelligence

Preset registry, searchable forms, official source/verification metadata.

## Milestone 4 — Advanced local processing

Background removal, face guidance, blur and lighting detection.

## Milestone 5 — Application kits

Thumb impressions, batch processing, ZIP export, document/PDF tooling.
