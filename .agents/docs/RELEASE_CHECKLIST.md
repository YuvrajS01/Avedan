# Release Checklist

- [ ] Production build succeeds
- [ ] Type-check passes
- [ ] Lint passes
- [ ] Unit/integration tests pass
- [ ] Core photo flow tested on mobile
- [ ] Core signature flow tested on mobile
- [ ] Camera permission denial has a useful fallback
- [ ] No image bytes are sent to analytics or backend
- [ ] Output file size and dimensions are shown before download
- [ ] Presets include source and verification dates
- [ ] Outdated/unverified presets are clearly marked
- [ ] No acceptance guarantee language is present
- [ ] Large images do not freeze the interface unacceptably
- [ ] Temporary object URLs are revoked
- [ ] Privacy messaging is visible and accurate
- [ ] Error states are user-actionable
